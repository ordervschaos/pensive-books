## Step 1 — computed stylometric lints (P1 → kernel)

**Where**: `proseLints()` — apps/web/src/features/dna/lib/novelDna.ts:1757 + twin _shared/novel-dna.ts. Parity-locked. No deploy/schema/UI.

**Already covered (do NOT port)**: monotone_rhythm (= per-scene wps_cv floor), dialogue_flatline, prose_echo, name_soup. Interiority/sensory/body/question/italic densities stay in the miner — discovery lenses, no universal threshold.

**1a. `em_dash_density`** (per scene)
- `(prose.match(/—|--/g)?.length / words) * 100 > cfg.emDashCeiling` → warn.
- LintConfig knob `emDashCeiling`, default 0.8. Reuse the existing per-scene stats loop.

**1b. `cadence_uniform`** (book-level)
- cv of per-scene sentence-length CVs < `cfg.cadenceSpreadFloor` → one warn (anchor first prosed scene).
- Gate: ≥12 prosed scenes. Knob default 0.12 (provisional — 1176 measures 0.100).
- CALIBRATION GATE: run metric on one human-authored EPUB import as negative control before trusting; if human book ≤ 0.12, lower the floor.

**Tests / success**: parity fixtures (em-dash-heavy scene; uniform-cadence book); twins emit identical issues; `tsc -p tsconfig.app.json` clean; 1176 fires em_dash on most scenes + cadence_uniform once; human control quiet.

## Step 2 — scene technique fingerprint (read-side)

**Where**: read-facts edge fn → factLedger.ts → SceneContent.observed_fingerprint. Same seam as R2 value_carrier.

**2a. Types (both twins)**

```ts
  closure?: "echo_opening" | "hard_cut" | "image_out" | "line_out" | "interior_out" | "other";

// SceneContent: observed_fingerprint?: SceneFingerprint  (output field, comment-only in dnaSchema like observed_establishes)
```

**2b. Edge fn** (supabase/functions/read-facts/index.ts)
- System prompt: task (4) TECHNIQUE FINGERPRINT, unconditional. JSON contract += "fingerprint".
- Server-side allowlist validation per axis (registryIds pattern); drop invalid; omit empty object.
- GOTCHA FIX: MAX_PROSE_CHARS=8000 truncates the TAIL but closure is judged from the ending →
  when over cap, send first 6000 + "[…]" + last 2000 instead of head-only.

**2c. Client** (factLedger.ts)
- FactReadResult += fingerprint?; writeSceneLedger writes observed_fingerprint, deletes stale value when read returns none (value_carrier honesty rule).

**2d. Bridge**: eval-bridge /read-facts deliberately NOT synced (verified: R2/grounding never were; standing feedback). factLedger degrades gracefully on bridge path.

**2e. Deploy + verify**
- `supabase functions deploy read-facts` (standing auth; also flushes pending R2 redeploy).
- Acceptance: ledger scan on 1176 → fingerprint distribution matches hand-mined ground truth
  (~60% closure=echo_opening, ~70% interiority_engine=tell_decoding).

**Cost**: ~150 prompt + ~60 output tokens/scene on an existing call. **Known noise**: adjacent enum flips between runs — fine for warn-severity consumers; revisit if step 3 wants hard gates.
