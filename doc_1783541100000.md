# Generalizing the Structure Miner: fingerprint → lint → generation

Design note, 2026-07-09. Context: `.dna-miner-1176-matrix.md` analysis found book-specific tics
(bookending 25/41, tell-decoding 29/41, prop-motif 24/41). Question: how to use this for ANY book.

## Reframe: graduate axes, not tics

"Weather bookends" is a 1176 fact. "Every scene has a closure strategy and adjacent scenes
shouldn't reuse it" is universal. The existing pair already models this:

- plan-side: `metaphor_domain` (SceneContent) → `metaphor_monotone` lint (novelDna.ts:1341)
- read-side: `observed_value_carrier` (read-facts output) → `value_asserted` lint (novelDna.ts:2040)

Generalize the 1176 clusters into enum axes:

| 1176 tic | axis |
|---|---|
| bookending | closure_type: echo_opening / hard_cut / image_out / dialogue_out / … |
| micro-tell decoding | interiority_engine: tell_decoding / memory / direct_thought / … |
| prop-as-motif | motif_carrier: prop / weather / body / sound / none |
| staccato climax | climax_cadence: staccato / sustained / none |
| metaphor domains | metaphor_domain (already shipped — the template) |

## Architecture: one substrate, three consumers

```
                scene prose
                    │ read-facts (extend existing read)
                    ▼
    observed_fingerprint on SceneContent        P1 traces (pure code from miner:
    {closure_type, interiority_engine,           em_dash, wps_cv, dialogue_ratio)
     motif_carrier, climax_cadence}                       │
                    │                                     │
    ┌───────────────┼─────────────────────────────────────┤
    ▼               ▼                                     ▼
VERIFY: generic   GENERATE: variety block —          VERIFY: computed
monotone engine   last-K fingerprints → avoid[]      stylometric lints
(one lint, N axes) in the render brief               (no LLM)
```

1. **Verify** — refactor metaphor_monotone into a generic monotone engine sweeping declared
   `{field, window, threshold}` axes; thresholds in LintConfig (genre presets tune).
2. **Generate** — fold last-K scenes' fingerprints into the render brief `avoid[]`:
   "last 3 scenes closed by echoing their opening — close differently." Same data the lint
   reads, injected as a negative constraint BEFORE prose instead of flagged after.
   This is the generate↔verify duality (docs/true-agent.md) made literal.
3. **Discovery** — the miner runs offline across books; residuals clustered; graduation =
   add one fingerprint field, which auto-inherits linting + variety injection.
   Prereq: normalize the miner residual output contract (1176 run mixed prose/snake_case/booleans).

## Sequencing

1. Port P1 trace computation into the shared kernel as computed proseLints (both twins, parity-locked). Free, works on every book incl. EPUB imports.
2. Fingerprint fields on SceneContent as `observed_*` (same pattern as observed_value_carrier), extracted by the existing read-facts call.
3. Generic monotone engine; re-register metaphor_monotone as its first axis.
4. Variety block in render brief from last-K fingerprints.
5. Miner contract fix + cross-book clustering loop.

## Design tension

metaphor_domain is plan-side (agent chooses, prose obeys); the fingerprint is read-side (sensed
after prose). Keep new axes READ-SIDE only — planning closure_type per scene is ceremony; sensing
recent closures and saying "vary" gets the benefit without bloating the planning surface. Promote
an axis to plan-side only if it proves to be a deliberate authorial choice like metaphor domain.
