# Can I generate a better book?

A working manual for an **AI agent** evaluating a generated book and improving it toward its brief.
"Better" has one definition here: **the finished book delivers its brief at gold standard.** Not
"well written in the abstract" — delivers *this* brief: its genre, heat, length, tone, success
criteria. Everything below is the loop for getting there.

Companion: per-book logs (e.g. `book-1150-gold-standard-log.md`) track one book's iterations.

---

## 0. The mental model: a resolution ladder that leaks

A book is generated by progressively compressing the author's intent down a ladder, then expanding
it back into prose:

```
BRIEF ──► FOUNDATIONS ──► SPINE ──► OBJECTIVES ──► BEATS ──► PROSE  ──►(REVISE)
(intent)  (cast/world/   (one-arc   (per-page    (per-page  (the words)
           tentpoles/     throughline  purpose)    plan)
           voice/ending)  + routes)
```

Every arrow is a **compression or expansion stage = a model call = a place intent can leak.** The
single most useful skill is *localizing which arrow dropped the thing you care about.* A property
mandated in the brief (say, explicit heat) can be present at the brief, survive foundations, and get
**laundered** into euphemism at the spine — three stages before the prose you were staring at.

> **Laundering** = a stage softens/abstracts a mandated property without dropping it outright
> ("passionate sex" → "the last pretense" → "the threshold of it" → fade-to-black). The mechanism
> fix (`brief-mandate-propagation.md`) exists to stop this; this doc is how you *catch* it when it
> still happens.

## 1. What "good" means — the conformance axes

Judge every book on these. Each maps to a brief field and a place it can fail.

| Axis | Brief source | Gold standard | Common failure |
|---|---|---|---|
| **Heat** | `content_type` + genre + success | intimacy rendered at the mandated explicitness, ON the page, as a recurring engine where the genre implies it | fade-to-black; one euphemized clause |
| **Length** | `scope.word_target` | within ~85–115% of target, weighted so the climax isn't starved | undershoot (pages written to "feels done") |
| **Genre/tone** | `genre` + `tone` | the genre promise sustained THROUGHOUT (a comedy stays funny, a thriller stays tense) | tonal drift — opens on-genre, ends earnest/lyric |
| **Success criteria** | `success_criteria` | the author's stated "done" test is met | partial — the literary half lands, the visceral half doesn't |
| **Craft** | voice_exemplar + rubric | causal scenes, value turns, subtext, payoffs; voice consistent | AI-tell crutches; motif saturation; flat pacing |
| **Coherence** | foundations + threads | facts/voice/threads consistent; seeds pay off | dangling tentpoles; contradicted facts |

A book is **gold standard** only when every axis is PASS *for that brief*. A beautifully written
book that fades-to-black on an explicit-ecchi brief is a FAIL, not a B+.

## 2. The evaluation toolkit (how to measure, cheap → deep)

Use the lightest tool that localizes the problem.

1. **Marker scan (seconds, free).** Regex the artifact for axis signals — heat words, comedy words,
   fade markers. I used this on 1150's spine routes to prove the comedy/heat DNA was in the routes
   but cooked out of the final spine text. Great for "is the property present at this layer at all?"
2. **Layer-localization trace (minutes, free).** Read the SAME story moment at each rung — tentpole →
   spine clause → beat → prose — and find the first rung where the mandated property softens. This is
   the highest-leverage diagnostic. It tells you *which stage to fix*, not just *that* something's off.
3. **Mandate gate (`mandate-gate.ts`, one judge call).** Per-axis PASS/PARTIAL/FAIL on a finished
   manuscript: length deterministic, heat/genre/success LLM-judged against the exact MANDATE block the
   generator saw. The automated backstop. Returns quoted evidence. Reports, never blocks.
4. **Editor's read (`evaluate-book` / `evaluate-core.ts`).** Full developmental edit vs the fiction
   rubric, map-reduce over the whole manuscript. Deep, ~$0.33/read. Use for craft + coherence, not
   for the binary mandate axes (the gate is cheaper for those).
5. **A/B harness (`/tmp/verify_heat.mjs` pattern).** Hold context + objective fixed, vary ONE control
   point, compare outputs. The only way to *prove* a lever works. Used to prove the MANDATE split
   carries heat (fade 1→0, on-page 2→5, length 2.2×).

Rule: never conclude "the model can't do X" from one bad output. A/B it — usually the property exists
upstream and a selection or a prompt-framing lost it.

## 3. The control surface (every lever, by stage)

What you can actually turn. Ordered by leverage (highest first).

### Brief (`books.brief` jsonb) — the root contract
- **`content_type`** `{level: closed|warm|explicit, note}` — derives the heat MANDATE. THE heat lever.
- **`scope.word_target`** — derives per-page length budgets (C4).
- **`success_criteria`, `genre`, `tone`** — the MANDATE block + VOICE block (`mandateContext`/`briefContext`).
- Leverage: highest. Every downstream stage reads this. A wrong/empty field here can't be fixed below.

### Foundations (`books.foundations`) — the creative constants
- **`voice_exemplar`** (pinned) — "stronger style anchor than any instruction" in the prose prompt.
  The most load-bearing single field for *voice*. Edit this to move register/diction wholesale.
- **`tentpoles`** (38 on 1150; `fluid`/`pinned`/`killed`) — the set-piece bank. **Pin** the ones that
  must appear; **kill** the off-brief ones. Under-curation = the model picks; over-banking = great
  material silently dropped. The heat/comedy of a book lives here as much as anywhere.
- **`art_theme`** (`comic` on 1150), **`cast`** (lie/want/wound/idiolect/tag), **`world`**,
  **`ending`** (pinned), **`argument`** (pinned).
- Leverage: high. Regenerating with edited foundations is cheaper than fixing prose.

### Spine (`books.spine`) — the throughline
- **`selected_route_id`** — pick among the generated routes. Routes differ in ordering/emphasis;
  selection can win or lose the comedy/heat balance.
- **`text`** (hand-editable; `pinned`) — the author can rewrite the one-arc directly.
- **`routes`/`proposals`** — regenerate for new options (avoid-list supported).
- Watch: routes can carry DNA the final `text` launders out (1150's case). Check both.

### Objectives → Beats → Prose — the per-page chain
- **Beats** (`page.metadata.beat`) — the concrete plan. Revise via `revise-beats`/beat chat. The beat
  is where fade-to-black gets authored (1150 pg23 said "close on the threshold of it"). Fix heat here
  and it propagates to prose.
- **Prose** (`page.content`) — regenerate via `beat-to-prose`. Reads voice_exemplar + MANDATE +
  per-page length. The last expansion.

### Cross-cutting knobs
- **`books.steers`** (per-layer free-text) — `steer.ts`; a steering instruction injected at a layer
  ("more comedic texture", "heat as a recurring engine"). The fastest non-destructive nudge. (null on 1150.)
- **`books.craft_notes`** (per-layer, tier-2 editable craft KB) — durable per-book craft guidance,
  stacked with the tier-1 immutable KB (e.g. `story-shapes.ts`). (empty on 1150.)
- **Candidates + judge** — sample N, keep best (beat-core, spine routes). More candidates = more spread.
- **Model tier** (`model-config.ts`) — OpenRouter Qwen/DeepSeek vs Anthropic. Cheaper tiers may comply
  less with the MANDATE; re-verify when the tier changes.
- **Pinning** — make any foundation/spine item immutable so regeneration can't drift it.

## 4. The improvement loop

```
  ┌─────────────────────────────────────────────────────────┐
  │ 1. MEASURE   gate + marker scan → which axes fail?       │
  │ 2. LOCALIZE  layer-trace → which STAGE first drops it?   │
  │ 3. INTERVENE pull the lever AT that stage (§3)           │
  │ 4. PROVE     A/B the change in isolation                 │
  │ 5. REGEN     re-run from that stage down                 │
  │ 6. RE-MEASURE gate again → axis flipped to PASS?         │
  │ 7. LOG       what worked / didn't (per-book doc)         │
  └─────────────────────────────────────────────────────────┘
```

Key discipline:
- **Fix at the highest stage that's wrong.** If heat dies at the spine, fixing prose is whack-a-mole;
  fix the spine and regenerate down.
- **One lever per iteration when proving.** Otherwise you can't attribute the win.
- **Re-measure with the same tool** you measured with, so deltas are comparable.
- **A regenerated upstream stage invalidates everything below it** — beats off an old spine, prose off
  old beats. Track which rungs are stale (see the per-book log's state table).

## 5. Failure-mode catalog (pattern → likely stage → lever)

| Symptom | Most likely stage | First lever to try |
|---|---|---|
| Fade-to-black on a heat-mandated brief | beat (then prose) | `content_type: explicit`; anti-launder; regen beats→prose |
| Comedy/tone drifts to earnest mid-book | spine selection + beats | steer "sustain the comic register"; re-pick route; pin comic tentpoles |
| Book ~half its target length | prose (no/ignored budget) | C4 per-page budget; regen; check climax weighting |
| Great material missing | foundations (tentpole attrition) | pin the must-haves; surface unrealized tentpoles |
| Motif saturation / self-parody | prose (no cross-scene budget) | whole-manuscript line-edit pass; motif ledger |
| Property in routes but not final spine | spine `text` compression | re-pick route or hand-edit text; steer the spine regen |
| Voice inconsistent across pages | prose (weak/absent exemplar) | pin a strong `voice_exemplar` |

## 6. Standing principles

- The brief is a **contract, not a vibe.** Heat/length/genre are deliverables with the same authority
  as voice. (This is the whole point of `brief-mandate-propagation.md`.)
- **Voice propagates for free; everything else must be made to.** If a property isn't foregrounded as a
  binding mandate, it decays at the first compression.
- **Localize before you intervene.** The layer-trace is worth more than ten prose regenerations.
- **Prove with A/B.** "It looks better" is not evidence; a held-context comparison is.
- **The gate confirms, the author decides.** Conformance scoring informs revision; it never auto-blocks.
