# What's actionable in `.dna-miner-1176-matrix.md`

The matrix is the Structure Miner's raw output for book 1176 (41 scenes, 53k words). It has two halves, and each half feeds a different pipeline:

- **P1 (trace matrix)** — cheap, deterministic per-scene stylometry. Feeds *computed lints* (no LLM needed).
- **P2 (residual ore)** — 252 LLM-observed techniques the trace metrics *couldn't* capture. Feeds the **graduation pipeline**: cluster → count across scenes → threshold → promote to a lint or a craft note.

R1 (`metaphor_monotone`) and R2 (`value_asserted`) already graduated from this file. The question is what's left in the ore.

## The core distinction: tic vs. technique

Every residual is one of two things, and the *frequency* decides which:

- **Rare + good → craft note** (tier-2 `books.craft_notes`): prescribe it, the model should do it more.
- **Ubiquitous → variety lint**: the model has a habit; detect and suppress repetition.

The same item ("weather bookend") is a lovely technique at 3/41 scenes and a tic at 13/41.

## Actionable items, ranked

### 1. Graduate R3: `scene_closure_monotone` (from P2)
25/41 scenes close by echoing their opening (gesture, weather, prop, refrain). Circular closure is a good move that has become the *only* move. Lint shape: track closure-type per scene, flag when the same closure strategy runs N scenes in a row or exceeds a book-level share. Same twin+parity pattern as R1/R2.

### 2. Graduate R4: `tell_decoding_saturation` (from P2)
29/41 scenes lean on "POV reads a micro-expression / decodes a physical tell." This is the interiority engine of the whole book — worth a density lint (flag runs of consecutive scenes using it) rather than a ban.

### 3. Computed lint straight from P1: em-dash density
`em_dash` averages ~1.2 per 100 words with *every* scene ≥ 0.74 — uniformly high, the classic LLM prose tic. This one needs no residual model at all: it's already a column in the trace matrix. Cheapest win in the file.

### 4. P1 outlier triage (per-scene fixes, no new code)
- **s8**: sensory 2.93 (3× book mean) — purple-patch candidate.
- **s5**: interiority 0.00 — the only scene with zero interior access.
- **s22**: 2,532 words — 2× median scene length; check if it's earning it.
- **s25, s29**: dialogue_ratio 0 — two silent scenes; fine individually, check spacing.
- **wps_cv sits in a tight 0.77–1.18 band across all 41 scenes** — sentence-rhythm *variance* is itself uniform. Every scene has the same mix of long and short sentences. A book-level "cadence fingerprint too stable" observation; candidate future lint.

### 5. Harvest craft notes (the rare good stuff)
A few residuals are genuinely distinctive, appear 1–2 times, and belong in tier-2 `craft_notes` as prescriptions, not lints:
- **Prop semantic transformation** (s40): one object passed between characters, accumulating meaning per handoff.
- **Sensory zoom-in gradient** (s26, s40): distant/ambient senses early → tactile/intimate late.
- **Dialogue back-loading** (s35): dialogue mass shifted to the final third for release.
- **Counterfactual narration of withheld words** (s8): narrate what a character *didn't* say.

### 6. Fix the miner itself (process debt)
The residual prompt isn't normalized — outputs mix prose sentences (s1, s3), snake_case features (s5, s12), key:value pairs (s25, s28), and even booleans/schema descriptors (s21 returned "enum/boolean" *field definitions*, s31 returned `: true` flags). Graduation requires clustering 252 heterogeneous strings by hand. Actionable: tighten the residual output contract (one canonical `snake_case_feature: one-line gloss` shape) so future runs cluster mechanically.
