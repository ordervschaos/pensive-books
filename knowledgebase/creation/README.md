# Book Creation Methods

This folder holds the structures used to **guide a user through creating a book**. Each method is its own actionable doc — pick the ones that fit the book, and follow the steps.

[`creation-methods.md`](creation-methods.md) is the deep research reference behind all of these (full tables, time investments, and citations). The docs here are the practical extractions.

---

## The creation pipeline

Creating a book is a sequence of choices. A guided flow walks the user through them in roughly this order:

1. **Choose a drafting approach** — *how* you'll work. → [`approaches/`](#approaches-how-you-write)
2. **Choose a structure** — the *blueprint* for the book. Routed by genre. → [`structures/`](#structures-the-blueprint)
3. **Build the engine** — characters and (if speculative) the world. → [character engine](building-blocks/character-engine.md), [world-building](building-blocks/world-building.md)
4. **Write** — using [hooks](building-blocks/hooks.md) to open and to end every chapter, sustained by a [routine](building-blocks/writing-routines.md).
5. **Revise** — impose structure with [reverse outlining](building-blocks/reverse-outlining.md).

Approach and structure are largely independent choices: you can discovery-write a Hero's Journey, or outline a Fichtean thriller.

## Approaches — *how you write*

| Approach | One-liner | Choose when |
|---|---|---|
| [Outlining](approaches/outlining.md) | Build the blueprint before the prose. | Complex plots; structure calms you; you want short revisions. |
| [Discovery writing](approaches/discovery-writing.md) | Write without a map; let the story emerge. | Planning kills your passion; you trust your instincts. |
| [Hybrid drafting](approaches/hybrid-drafting.md) | Discover some, plan some. | Neither pure approach fits — the most common case. |

## Structures — *the blueprint*

Route by what the book is. The genre is a contract; pick the structure that delivers it.

| Structure | Shape | Best for |
|---|---|---|
| [Snowflake Method](structures/snowflake-method.md) | 10 expanding passes from one sentence. | Blank-page paralysis; intricate plots; you like building up. |
| [Hero's Journey](structures/heros-journey.md) | 12 stages, known → unknown → return. | Fantasy, sci-fi, epics; single transformative protagonist. |
| [Story Circle](structures/story-circle.md) | 8 cyclical steps. | Character-driven, episodic, screen-style; a lighter monomyth. |
| [Save the Cat!](structures/save-the-cat.md) | 15 beats at fixed % markers. | Commercial fiction; tight, measurable pacing. |
| [Fichtean Curve](structures/fichtean-curve.md) | Escalating crises, in medias res. | Thrillers, mysteries, suspense; relentless momentum. |
| [Romancing the Beat](structures/romancing-the-beat.md) | 6 relationship beats to HEA/HFN. | Romance, or any relationship-centered story. |
| [Memoir](structures/memoir-structure.md) | Curated personal transformation. | Non-fiction built on lived experience. |
| [Self-Help](structures/self-help-structure.md) | 5-part arc + Hook-Book-Look-Took chapters. | Prescriptive non-fiction that promises a change. |

## Building blocks — *used within any structure*

| Block | What it gives you |
|---|---|
| [Character engine](building-blocks/character-engine.md) | Ghost / Lie / Want / Need — the psychology that *generates* plot. |
| [World-building](building-blocks/world-building.md) | Sanderson's Laws + system parameters for magic/tech that doesn't break tension. |
| [Hooks](building-blocks/hooks.md) | Opening hooks and chapter-end springboards that keep pages turning. |
| [Reverse outlining](building-blocks/reverse-outlining.md) | The editorial x-ray that finds structural flaws after drafting. |
| [Writing routines](building-blocks/writing-routines.md) | Daily regimens to actually finish the manuscript. |

## Quick routing by genre

- **Fantasy / sci-fi / epic** → [Hero's Journey](structures/heros-journey.md) + [world-building](building-blocks/world-building.md) + [character engine](building-blocks/character-engine.md)
- **Thriller / mystery** → [Fichtean Curve](structures/fichtean-curve.md) + [hooks](building-blocks/hooks.md)
- **Romance** → [Romancing the Beat](structures/romancing-the-beat.md) + [character engine](building-blocks/character-engine.md) (build both leads' Lies)
- **Commercial / book-club fiction** → [Save the Cat!](structures/save-the-cat.md) or [Story Circle](structures/story-circle.md)
- **Literary / character study** → [Story Circle](structures/story-circle.md) + [character engine](building-blocks/character-engine.md)
- **Memoir** → [Memoir framework](structures/memoir-structure.md)
- **How-to / prescriptive non-fiction** → [Self-Help framework](structures/self-help-structure.md)
- **Stuck / overwhelmed by any of the above** → start with the [Snowflake Method](structures/snowflake-method.md)

> Related: once a draft exists, the [evaluation rubrics](../evaluation/) (fiction / non-fiction) judge whether it delivered on the structure it chose.
