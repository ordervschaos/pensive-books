# DNA Tree Studio UI critique — implementation summary

Implemented all 15 items from `doc_1783534158253.md` (the UI critique of book 1229's `/dna/tree` screenshot).
Files touched: `DnaTreePage.tsx`, `BriefSection.tsx`, `panels.tsx`, `treeChrome.tsx`, `EditableField.tsx`,
`Subtree.tsx`, `dnaJourney.ts`, `dnaSchema.ts`, `AgentRail.tsx`.

## REMOVE
1. **Legend row → popover.** Status dots / stale key / ∴↯ / "plumbing is AI-maintained" now live behind a
   `?` `QuickToggle` in the merged journey row, rendered as a small fixed popover. The context-focus green/blue
   legend moved into `FocusPanel` itself (`panels.tsx`).
2. **json/fork → `⋯` overflow menu**, joined by `history` (previously its own toggle). One dropdown, closes on
   selection.
3. **Logline caption → tooltip.** Removed the always-visible sentence under the seed's logline field; the same
   text is now a `title` on the LOGLINE label via a new `EditSpec.hint` field (generic, reusable by any field).

## REARRANGE
4. **Stage-aware brief collapse.** `BriefOrigin` takes `open`/`onToggleOpen`; collapses to a one-line summary
   (`genre · tone · heat · word target · "idea…"`) once `buildJourney`'s `nowIndex > 0` (past premise), unless
   the author has explicitly toggled it (persisted per book in `localStorage`, same pattern as `railOpen`).
5. **Action bar merged into the journey strip.** `JourneyStrip` gained a `right` slot prop; on the tree tab the
   health pip + Decompose + expand/collapse + timeline toggle + key toggle + overflow menu all render in that
   slot, on the same row as the stage pills. The standalone action bar now only renders off the tree tab (a
   slim health-pip + Decompose + overflow bar).
6. **Rail close ✕** — already folded into `AgentRail`'s own header row in a prior commit; verified, no change
   needed.

## MODIFY
7. **Health pip literacy** — `2× 21⚠ →` → `2 errors · 21 warnings →`.
8. **Heat select width** — `flex:1` → fixed `200px`.
9. **Pluralization** — `dnaJourney.stageProgress` gap labels now use a small `plural()` helper ("1 scene needs
   prose", "2 scenes need prose").
10. **Book name → link** to `/books/:slug`.
11. **Tab targets** — slightly larger padding/font; working tabs (overview/tree/voice) visually separated from
    read-only projections (analytics/meters/characters/story) by a thin divider.
12. **Rail header affordance** — the `auto` icon pill became a labeled two-position segment (`manual` | `auto`),
    matching the existing `fast`/`deep` segment's styling; tooltips were already present from a prior commit.

## ADD
13. **Persistent `read →` CTA** in the top bar (all tabs), calling the existing `renderAndRead`.
14. **Clickable gaps** — each "what's left" gap now reveals its stage in the tree AND opens the agent rail,
    which already surfaces the mapped next-step nudge (`dnaJourney.currentObjective` / `AgentRail`'s
    `NEXT_STEP_MESSAGE`) — reused existing plumbing instead of duplicating a stage→message table.
15. **`/` hint** on the Search toggle's tooltip.

## Verification
`npx tsc -p tsconfig.app.json --noEmit` — clean. `eslint` on all touched files — 0 errors (pre-existing
fast-refresh warnings only, unrelated to this change). Not yet manually driven in a browser.
