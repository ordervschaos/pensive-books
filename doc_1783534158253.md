# DNA Tree Studio — UI critique (remove / rearrange / modify / add)

Screenshot reviewed: book 1229 "Mastering Freedom v3", `/dna/tree`, Terminal skin, agent rail open,
book at stage 5 (PROSE 11/12). Code grounded in `apps/web/src/features/dna/` (DnaTreePage, treeChrome,
panels, BriefSection, AgentRail).

## The one-sentence diagnosis

On a mature book, the **tree tab shows no tree**: five rows of chrome plus a full-width, always-expanded
brief push the working surface entirely below the fold — the page's *visual hierarchy* is inverted
(reference material on top, working material hidden).

Measured from the screenshot (~1100px viewport height):

| Band | Height | Content |
|---|---|---|
| Top bar | ~48px | book name · search/editor toggles |
| Tab strip | ~40px | 7 tabs |
| Action bar | ~36px | health pip · timeline/history/lens · expand/collapse/json/fork |
| Journey strip | ~64px | 5 stages + "what's left" |
| Legend | ~32px | status dots · stale key · ∴/↯ key · "plumbing is AI-maintained" |
| **Brief** | **~600px** | idea (7 paragraphs) + 6 fields + derives-cue |
| Tree | remainder | seed row + logline + first premise line |

The chrome-to-content ratio is the core problem; everything below is a consequence or a lesser cousin.

---

## REMOVE (from permanent chrome — not from the product)

1. **The legend row** (`DnaTreePage.tsx:731-751`). Status-dot key, "amber dot = stale", "∴ therefore ↯ but",
   "plumbing … is AI-maintained" — this is *documentation rendered as chrome*. It never changes, teaches
   only on first read, and costs a permanent row. Move it behind a small `? key` QuickToggle-popover in the
   action bar. The conditional context-legend part (green/blue meaning, `:743-750`) belongs inside the
   FocusPanel, which is the thing that lit those hues.

2. **`json →` and `fork →` from the action bar** (`DnaTreePage.tsx:644-648`). Developer-grade utilities
   with equal billing to core actions. Fold into one `⋯` overflow menu (with history, which is used rarely).

3. **The static caption under the logline** ("the logline — derived from the brief (the origin) above;
   ≠ the raw idea. Refine it with the lab."). Same legend-as-chrome anti-pattern per-row; demote to a
   `title` tooltip on the LOGLINE label.

## REARRANGE

4. **Stage-aware brief collapse** — the big win. `BriefOrigin` (`BriefSection.tsx:125-139`) always renders
   every field expanded. Once the tree is past foundations (`buildJourney` already knows), default it to a
   single summary row:
   `▸ BRIEF — MANDATE   Romantic Comedy Ecchi · warm, lyrical, playful · Explicit · 8,000 words · "A newly bought slave girl…"`
   Click to expand; persist the open state per book like railOpen/timelineOpen already do. The brief is
   "the constant origin" — on a drafting book it is *reference*, not *work in progress*. (Keep its position
   above the tree; the derives-cue stays inside the expanded state.)

5. **Merge the action bar into the journey strip** (`DnaTreePage.tsx:617-650` + `panels.tsx:71-129`).
   The health pip is progress vocabulary — it belongs next to the stages. Right-align the tree-only
   toggles (timeline / history / lens / key / ⋯ overflow) on the same row. Result: 5 chrome rows → 4,
   and the two progress readouts stop competing.

6. **Rail close ✕ row** (`DnaTreePage.tsx:561-563`) — a dedicated 30px row for one glyph. Move the ✕ into
   AgentRail's own header line (which already carries auto/fast/deep/⏱/✎).

## MODIFY

7. **Health pip literacy** (`DnaTreePage.tsx:620-627`): `2× 21⚠ →` is glyph soup. Render
   `2 errors · 21 warnings →` (colors already carry severity).

8. **Heat select width** (`BriefSection.tsx:108-113`): `flex: 1` stretches a dropdown across the entire
   content column — the widest control on the page for the smallest decision. Content-width (~200px).

9. **Pluralization** (`dnaJourney` gapLabel): "1 scenes need prose" → "1 scene needs prose".

10. **Book name → link home**. The studio suppresses the main nav, and the only ways out are Story-tab
    "read" or browser-back. Make the book name in the top bar (`DnaTreePage.tsx:586`) a link to
    `/books/:slug`.

11. **Tab targets** (`DnaTreePage.tsx:602-613`): 7 tabs at 10.5px uppercase — small hit targets and low
    scent. Slightly larger padding/size; consider grouping read-only projections (analytics · meters ·
    characters · story) visually apart from working surfaces (overview · tree · voice).

12. **Rail header affordance** (`AgentRail`): `∞ auto · fast · ⚡ deep · ⏱ 30 · ✎` is an unlabeled icon
    cluster controlling the most consequential behavior in the studio (autonomy). At minimum tooltips;
    better, a two-position labeled segment (manual / auto) + effort toggle.

## ADD

13. **A persistent primary action: `read →`** in the top bar, all tabs. `renderAndRead` exists
    (`DnaTreePage.tsx:277-282`) but is only reachable via the Story tab. On the screenshot book (11/12
    scenes written) reading the draft is *the* payoff action and it is invisible. This is the missing
    call-to-action.

14. **Actionable gaps**: "6 beats need scenes · 1 scene needs prose" (`panels.tsx:121-126`) should be
    clickable — open the rail and send the mapped nudge (`NEXT_STEP_MESSAGE` already exists,
    `AgentRail.tsx:32-43`). Turns the progress readout into the work loop.

15. **`/` hint** on the Search toggle (`title="Search ( / )"`), since the shortcut already exists
    (`DnaTreePage.tsx:472-483`).

## Deliberately NOT proposed

- Moving the brief to the Overview tab — the decision record places the origin above the tree; collapse
  solves the cost without relitigating the placement.
- Removing the journey strip — it is the sense-of-place the flat tree lacks; it gets *more* prominent
  after the merge, not less.
- Touching proposal readability in the rail — NORTH_STAR §6 rule 8 (accept/deny = state change, not
  erasure) stands.

## Priority

- **P2 (wayfinding/payoff):** #13 read CTA · #10 book-name link · #14 clickable gaps.
- **P3 (polish):** #7 pip label · #8 heat width · #9 plural · #2/#3 overflow+tooltip · #11 tabs · #12 rail header · #15 `/` hint.
