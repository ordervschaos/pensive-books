# Agent Hardening & Agent Evals — how pensive benefits (academic framing)

## Placement
This is a *meta* concern sitting above the DNA agent (AgentRail): not a feature, but the
discipline that turns a capable model into a reliable product. It touches every AI surface —
generation, verify layer, durable tasks, provider switch.

## The core distinction (why it matters)
- **Capability** = can the model produce a good book *once*.
- **Reliability** = does the *system* produce one *every time*.
- **Evals** measure the capability→reliability gap. **Hardening** closes it.
- Together = a **control loop**: eval senses, hardening acts. Same generate↔verify duality as
  `docs/true-agent.md`.

Failure modes of doing only one:
- Hardening w/o evals → robust but blind to quality.
- Evals w/o hardening → measuring a flaky substrate → signal is noise.

Pensive's product bet (M1 "The First Read") *is* a quality claim, so this loop is the moat, not
hygiene.

## The system (stakeholders / parts)
- **Actor**: the DNA agent — tool-using loop over `book_nodes`, proposes/applies ops.
- **Action boundary**: `validateOps` (fail-closed), structural lints (`PARENT_KIND`).
- **Memory/grounding**: scene ledger, entity registry, continuity digest, read-repair loop.
- **Durability**: task rows, self-chaining past ~150s worker ceiling, pg_cron watchdog, tree
  versions (save points).
- **Observability**: `ai_calls` (every Claude/OpenRouter call logged at one chokepoint).
- **Judges**: `ai_call_evals` (per-call LLM-as-judge), `evaluate-book` rubric (per-book editor's
  read), verify-layer lints (inline critics).

## Agent hardening → maps to existing machinery

| Academic concept | Literal meaning | Lives in pensive as | Gap |
|---|---|---|---|
| Constrained action space / least-privilege | act only through typed, validated ops | `validateOps` fail-closed boundary, PARENT_KIND lints | ensure no write path bypasses it |
| Grounding / faithfulness | tie output to retrieved state, not invention | scene ledger, entity registry, continuity digest, read-repair | grounding coverage unmeasured |
| Reliability engineering (idempotency, checkpointing, resumability) | long-running stochastic actor survives crashes | durable tasks, self-chain, watchdog, tree versions | mature |
| Context engineering | control window contents for stable behavior | anchors-not-fences, digest fold, @-mention tray | "deterministic context hydration" (Later) |
| Graceful degradation | stay timeout-safe under limits | prose streaming proxy, ai_provider switch | — |

Hardening principle: **the verify-layer lints are hardening, not eval** — they *block* bad ops
before they persist. An eval that runs as a guardrail is a **generator–critic loop**.

## Agent evals → three altitudes (bottom two exist, top is thin)

1. **Outcome eval** — `evaluate-book` rubric = LLM-as-judge at artifact level (~$0.33/read).
   The North Star read-through bar.
2. **Trajectory / process eval** — `ai_call_evals` per call; PM's *read-round-trip-per-turn*
   metric = a real agent-efficiency SLO. Academic: **process supervision** vs outcome supervision.
   Judge the path, not just the destination (wasted tool calls, redundant reads).
3. **Inline critics** — verify lints (`shape_unmapped`, `dead_arc`, `reader_confusion` cold-read,
   structure-miner graduates). Eval-as-guardrail.

### The missing leg: a regression suite
A **golden-set** of books re-run on every prompt/model change. The DeepSeek tier switch currently
rests on an ad-hoc `model-prose-compare` run, not a standing benchmark. For a stochastic system,
an offline eval corpus is the only defense against silent **quality regression** (drift when a
model or prompt changes). That corpus = your taste encoded as tests = the durable asset.

## What to do with it (concrete)
1. Freeze a golden-book regression set; gate DeepSeek + every prompt edit on it.
2. Promote `ai_call_evals` from on-demand to CI-style gates on the agent's hot paths.
3. Name the two tiers: verify lints = *hardening* (block), rubric+judge = *eval* (score).
   Calibrate the five **human gates** / auto-accept by which lints earned trust to drop
   supervision.
